# Deployment Guide - Railway.app

This guide walks you through deploying **Zenith Atelier** (full-stack) to Railway.app.

## Prerequisites

- GitHub account (to connect your repo)
- Credit card (Railway requires one, but offers $5/month free credits)
- All code pushed to GitHub

## Step 1: Create a Railway Project

1. Go to [railway.app](https://railway.app)
2. Sign up with GitHub
3. Click **"New Project"** → Select **"Deploy from GitHub repo"**
4. Authorize Railway to access your GitHub
5. Select your **Zenith Atelier** repository

## Step 2: Add PostgreSQL Database

1. In your Railway project, click **"Add Service"**
2. Select **"Database"** → **"PostgreSQL"**
3. Railway will automatically create a PostgreSQL instance
4. The `DATABASE_URL` will be automatically set in environment variables

## Step 3: Configure Environment Variables

1. Go to your Railway project → **Variables**
2. Click **"Add Variable"** and add the following:

```
DATABASE_URL=<auto-generated by Railway>
PORT=3000
NODE_ENV=production
CLIENT_ORIGIN=https://your-railway-domain.up.railway.app
JWT_SECRET=generate_a_random_secret_key_here
EMAIL_SERVICE=gmail
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_app_password
RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
ADMIN_EMAIL=admin@zenith-atelier.com
ADMIN_PASSWORD=your_admin_password
```

3. Save all variables

## Step 4: Deploy

1. Railway will automatically detect your project type
2. It should auto-build and deploy
3. You can watch the deployment logs in real-time

## Step 5: Get Your Public URL

After deployment:
1. Go to **Deployments** → Latest deployment
2. Click **View Logs** to see if it's running
3. Your app will be accessible at: `https://your-app.up.railway.app`
4. Using this URL in frontend code

## Step 6: Run Database Migrations

After first deployment:
1. Go to Railway project → **Plugins** → **PostgreSQL**
2. Click **PostgreSQL** → **Data** tab
3. Open **PG Admin** or use SSH:

```bash
railway run npm run seed:admin
```

This creates the admin user and tables.

## Step 7: Update Frontend API URLs

In your frontend code, replace:
```typescript
// Old (local development)
http://localhost:3000

// New (production)
https://your-app.up.railway.app
```

## Troubleshooting

### Build Fails
- Check logs: Railway → Deployments → Logs tab
- Ensure all dependencies are in `package.json`

### Database Connection Error
- Verify `DATABASE_URL` is set correctly
- Check PostgreSQL service is running (should show in Services)

### CORS Errors
- Make sure `CLIENT_ORIGIN` matches your frontend URL
- Update `CLIENT_ORIGIN` in backend environment variables

### Port Issues
- Railway automatically assigns a PORT
- Backend should use `process.env.PORT ?? 3000`

## Free Tier Limits

- $5/month free credits
- Each app uses ~$2-3/month
- PostgreSQL uses ~$3-4/month
- (Total is often within free tier)

## Domain Setup (Optional)

To use a custom domain:
1. Go to Railway project → **Settings** → **Domains**
2. Add your custom domain (e.g., zenith-atelier.com)
3. Update DNS records as Railway instructs
4. Update `CLIENT_ORIGIN` to your custom domain
